# Revisi Blueprint Portfolio untuk Instruksi UTS

Acuan: `blueprint(2).md` dan `UTS_TRPL26A1_Bahasa Inggris 1.pdf` (1 halaman).

## Perbandingan dan koreksi asumsi

| Isi blueprint lama | Instruksi UTS | Koreksi |
|---|---|---|
| Navbar: Home, About, Skills, Projects, Moments, Contact | 5 menu wajib: Home, About, Software Review, Blog, Contact | Jadikan lima menu wajib sebagai **navigasi utama**. Skills, Projects, Moments boleh tetap sebagai konten tambahan. |
| Projects membahas pengembangan DLMS | Software Review: review satu aplikasi / software | Proyek RDW DLMS **bukan otomatis review aplikasi**. Tambahkan Software Review khusus; versi ini memilih Google Sites. |
| Moments berupa galeri foto | Blog harus ada, dan setiap menu perlu tulisan | Galeri foto **bukan pengganti blog**. Tambahkan artikel pengalaman drama dengan tiga foto. |
| Fokus luas pada 3D, meteor, UI/UX | Grammar 40%, content 30%, creativity 20%, design 10% | Prioritaskan tulisan dan tense, cukup gunakan desain yang rapi. Animasi bukan unsur wajib. |
| Usulan upload GitHub Pages | Soal menyebut website builder | GitHub Pages adalah **hosting**, bukan editor website builder. Untuk kepatuhan paling jelas, susun 5 halaman di Google Sites/Wix; atau minta izin dosen untuk situs kustom. |
| Semua aset diasumsikan ada di assets.zip | ZIP terkirim tidak berisi assets | Foto lama / favicon belum tersedia; hanya foto drama yang dapat ditambahkan dalam revisi ini. |
| Konten DLMS seolah aplikasi desktop sudah berjalan | Konten harus akurat | Pertahankan kata **working on**, **goal**, dan **designed to** jika fitur belum diverifikasi. |
| Caption foto seperti `dlms-architecture.jpeg` | Foto harus sesuai isi | File `.jpeg` disebut foto acara, tetapi `.png` adalah schematic; jangan tertukar atau memberi klaim keliru. |

## Struktur yang disarankan
1. **Home** — pengantar diri, status sekarang, link ke portfolio/proyek.
2. **About** — perkenalan, pendidikan, kegiatan/skills, akun sosial media (sesuai yang Anda setujui untuk ditampilkan).
3. **Software Review** — Google Sites: fungsi, fitur, pro-kontra, penilaian praktis setelah mencoba aplikasinya.
4. **Blog** → **Drama Observation** — *A Midsummer Night’s Dream*: alur singkat, tokoh/adegan favorit, refleksi pengalaman, 3 foto.
5. **Contact** — alamat email dan link sosial media yang aktif.

**Konten tambahan di portfolio coding** boleh tetap ada: Skills, Projects, Moments; cukup pastikan dosen mudah menemukan kelima menu wajib.
